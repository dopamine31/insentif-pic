# 💰 Summary Insentif PIC - Modular Edition

Aplikasi web profesional untuk rekap insentif PIC dengan arsitektur modular, 
PIN ter-hash di Supabase, dan siap deploy ke GitHub Pages.

## ✨ Fitur Utama

- 🔐 **PIN Authentication** — hash SHA-256 di-query langsung dari Supabase
- 📁 **Struktur Modular** — HTML, CSS, JS dipisah (ES Modules)
- 📊 **CRUD Lengkap** — Create, Read, Update, Delete untuk Periode & Sekolah
- 📸 **Upload Bukti** — auto-upload ke Supabase Storage (5MB limit)
- 🗑️ **Auto Cleanup** — file otomatis dihapus saat data dihapus
- 📱 **Responsive** — optimal di mobile & desktop
- 🔒 **Row Level Security** — Supabase RLS aktif
- 🔄 **Auto Refresh** — data update otomatis setiap 60 detik
